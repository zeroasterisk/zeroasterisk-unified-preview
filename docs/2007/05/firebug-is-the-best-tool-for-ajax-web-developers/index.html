Firebug is the best tool for AJAX web developers

May 10, 2007
2007

Firebug is a fantastic Firefox Add-On which allows realtime viewing and editing of a page’s DOM, CSS, etc. as well as net usage reports, and even JS timing and profiling.

If you work on the web, it’s well worth your time to familiarize yourself with this tool.
