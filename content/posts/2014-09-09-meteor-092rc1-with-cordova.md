# Meteor 0.9.2-rc1 is fun to play with, Cordova support functional

Last night I started playing with meteor --release 0.9.2-rc1.

It's wonderful! The local development and hot-code-push is a great improvement. Builds were painless (mostly).

The hot code push works brilliantly in the simulator. This is going to be a game changer for mobile development with Meteor.
